## Requirements

- Python 3.10 or later
  - libraries: pandas, numpy, matplotlib, seaborn, scikit-learn, networkx
- Jupyter Notebook

## How to Use

### RQ1

To reproduce the results of RQ1, run the Jupyter Notebook `RQ1/scripts/result-analysis.ipynb`. The notebook contains the code to analyze the results of the experiments conducted to answer RQ1.

#### If you want to generate the coverage records using the modified AFL++:

The directory `RQ1/aflpp-modi` contains the modified version of AFL++ used in the experiments. To use it, follow these steps:

1. Clone the AFL++ repository from the official repository
2. Modify the AFL++ source code regarding the changes in the `RQ1/aflpp-modi` directory
   1. `include.diff` and `src.diff` contain the changes made to the AFL++ source code. The full files are also provided under the `aflpp-modi/implementation` directory.
   2. Copy the custom mutator implemented in `aflpp-modi/implementation/custom_mutators/examples` to the AFL++ source code directory.
3. Compile the modified AFL++ source code
   1. rebuild by running `make all & make install` in the AFL++ source code directory
   2. compile the custom mutator by `cc -O3 -fPIC -shared -g -o custom_post_run.so -I../../include set.c custom_post_run.c` in the `AFLplusplus/custom_mutators/examples` directory.
   3. Set the environment variable `AFL_CUSTOM_MUTATOR_LIBRARY` to the path of the compiled custom mutator library. E.g., `export AFL_CUSTOM_MUTATOR_LIBRARY="/AFLplusplus/custom_mutators/examples/custom_post_run.so"`
4. Run the modified AFL++ to generate the coverage records.

The coverage records will be generated in the `<output_dir>/records.csv` file.

### RQ2

To reproduce the results of RQ2, run the Jupyter Notebook `RQ2/scripts/trace-process.ipynb`. The notebook contains the code to analyze the results of the experiments conducted to answer RQ2.

## Description

### RQ1

The directory `RQ1` contains the code and data used to answer the first research question.

- `aflpp-modi`: Contains the modified version of AFL++ used in the experiments.
- `data`: Contains the data used in the experiments.
  - Top level under the `data` directory contains the analyzed data `{subject}.csv`.
  - Under the `records` directory, raw records of the experiments are stored.
- `figs`: Contains the figures generated by the analysis.
- `script`: Contains the Jupyter Notebook to analyze the results.

### RQ2

The directory `RQ2` contains the code and data used to answer the second research question.

- `data`: Contains the data used in the experiments.
  - Note: Currently, the repository only contains the data for the subject `delta` due to the size of the data. The complete data will be available after the paper is accepted.
- `figs`: Contains the figures generated by the analysis.
- `script`: Contains the python scripts and Jupyter Notebook to analyze the results.
